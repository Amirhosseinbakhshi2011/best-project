## About

This is the first project I built with **Next.js**, **React**, and **TypeScript** and successfully deployed to production.  
It marks the beginning of my journey shipping real, hosted web applications.

---

## Tech Stack

- **Next.js 14** (App Router)
- **React** + **TypeScript**
- **Tailwind CSS** (styling)
- **Vercel** (deployment)

---

## Getting Started

```bash
git clone https://github.com/Amirhosseinbakhshi2011/best-project.git
cd best-project

npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

It was my first real hosted project. From here I learned how powerful and productive the Next.js + TypeScript stack is for modern web development.
